# PostgreSQL Transactions — Interactive Lecture Deck

Clean, light-mode presentation site with 15 progressive SQL examples (from `BEGIN`/`COMMIT` basics to `SAVEPOINT`, isolation levels, `FOR UPDATE` row locks, `SERIALIZABLE` write skew, deadlocks, and atomic CTE patterns).

## Quick Start

- **Easy Launch (Windows):** Double-click **`START.bat`** — starts Vite and opens the presentation automatically.
- **Offline / No Node:** Open **`dist/index.html`** directly in Chrome or Edge.

## Lecture Controls

- **`Intro · ACID` / `Examples (01–15)` / `Isolation Table`:** Switch sections cleanly from the top bar.
- **Left / Right (`←` / `→`):** Navigate between examples `01`–`15`.
- **`Step Run`:** Walk through SQL statements (or Window A vs Window B steps) while updating the live query results on the right.
- **`Scroll All`:** Toggle between focused lecture slides and a full scrollable reference page.
- **`XL Font`:** Enlarge SQL code and query result tables for classroom projectors.
- **`Setup SQL`:** Open and copy the one-time `CREATE TABLE` script (`txlab` schema) for live demos.
