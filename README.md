# PostgreSQL Transactions — Visual Presentation (`BD_18.11`)

## Quick Start (Easy Launch)

- **Option 1 (Recommended):** Double-click **`START.bat`** — automatically installs packages if needed, launches the server, and opens the presentation in your browser.
- **Option 2 (Zero-setup / Offline):** Open **`dist/index.html`** directly in Chrome/Edge (single self-contained HTML bundle).

## Presenter Controls
- **Keys `1`–`6`:** Jump directly to sections `01`–`06`.
- **`Projector XL` (top-right):** Enlarges SQL editor font sizes for classroom projectors.
- **`Step Run` / Trace Pills:** Step through SQL transactions line-by-line with live DB state & `psql` output.
- **`Copy`:** Copies the full SQL block to clipboard.
